# Madni Kumboh — Portfolio

React and Vite portfolio featuring projects, skills, professional biography, portrait and resume downloads.

## Development

Requires Node.js 24. Run `npm ci`, then `npm run dev`.
Run `npm run build` to generate `dist`, and `npm test` for production interaction checks using JSDOM.

## GitHub Pages

Deployment URL: https://madnikumboh.github.io/madnikumboh-portfolio/#/

In repository Settings → Pages, select **GitHub Actions** as the source. The workflow builds and deploys on every push to main, and can also be run manually from Actions.

Vite base is `/madnikumboh-portfolio/`; PDF links and assets support this subdirectory. All sections remain accessible through ordinary scrolling. Contact form opens an email draft for the visitor to send.

The portrait and PDF are supplied by Madni Kumboh. Workspace images are illustrative AI-generated assets. Project artwork is illustrative.
